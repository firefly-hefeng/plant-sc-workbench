# 植物单细胞注释前分析工作台

在 Windows 双击 **启动工作台.cmd**，或运行 `Start-Workbench.ps1`。默认入口为 [本机工作台](http://127.0.0.1:8876)。所有文件读取和计算在本地进行。项目目录独立保存数据指针和版本化任务，不要求复制或上传测序文件。

每个分析步骤都内置项目工作区。一组页签用于浏览文件、预览内容、选择上游输出和查看本步文件，另一组用于对照图表和任务。可以一边调整质控阈值，一边核对逐细胞表和质控图。点击“从上游输出选择”，按任务和捕获选中产物，再点“用作本步输入”。已有任务的 H5AD 会保留父任务关系。点击“展开工作区”可放大两个分区。侧栏也可打开[独立分区工作区](http://127.0.0.1:8876/panes)。

## 共享演示

克隆后运行 `python share/serve.py`，访问 [只读演示](http://127.0.0.1:18976)。此模式仅需要 Python 标准库，自带公开拟南芥数据的 FastQC、MultiQC、质控表和交互 UMAP。首页右上角可切换两个项目。若使用 Cloudflare Quick Tunnel，请将隧道目标设为此演示端口 18976。本地分析服务使用 8876。

## 第一次使用

新机器先运行 `Setup.ps1` 安装计算环境，然后双击启动工作台。

若一个 H5AD 包含多个物理捕获，可先用工作台工具 `split_captures` 选择捕获字段，或运行 `python -m backend.capture_inputs --help`。输出的文库清单可直接送入质控；批次信息可以单独指定。

聚类后的可选注释可通过工作台工具 `annotate_clusters` 或 `python -m backend.annotation --help` 调用。输入 H5AD 需含原始整数 `layers/counts` 与主分区 `obs/leiden`。按物种、器官、模态和组装匹配文献面板，结果包含逐条码标签、拒判理由、逐簇标记证据和各捕获的注释覆盖率。现有面板覆盖 TAIR10 拟南芥根或叶的 scRNA，以及雄配子体的 snRNA。[基准评测设计](lab-notebook/010-上游工作台基准评测设计.md)
1. 选择“新建项目”，填写名称，可指定已有工作目录。可从本机文件、10x 输出目录或样本表开始。“使用示例矩阵”载入已登记的拟南芥花分生组织单核数据。
2. 在“测序与定量”接入 FASTQ，在“质控与清洗”接入矩阵，或从该步的定量任务列表接入结果。可直接引用本机文件或目录，也可把文件或整个目录上传至项目的 imports 文件夹。识别时自动配对 raw/filtered、合并同一 FASTQ 前缀的多个 lane。核对物种、模态与捕获关系。基因轴支持唯一推荐时，界面预选参考集；跨参考或无法判断时请指定组装。独立样本和捕获关系可在“编辑”中修订。
3. 在质控页点击“按当前文库运行全流程”，或逐个工作位预览与修改。仅有过滤矩阵也能开始分析。灰色缺项会说明所需文件或工具。文库级双细胞默认只报告；质体和线粒体没有通用硬阈值。
4. 如需单独审核质控，在“质控与清洗”点击“执行清洗并保存对象”。审核后前往“降维与批次诊断”，选择来源，点击“继续降维与聚类”。工作台沿用已冻结的条码与原始计数。
5. 在“文件管理器”浏览项目和文库目录，可新建文件夹、复制文件或在本机资源管理器中打开。“结果可视化”按任务查看和导出图表；“任务与接口”显示状态、来源、模块输入输出。各页面可独立收藏。
6. “降维与批次诊断”和“聚类与比较”分别提供各模块的 H5AD 文件入口和上游任务选择器。Leiden 可以从仅含细胞连通权重的对象开始。每步的“本步文件”可定位输入目录，按任务查看、预览和下载真实输出。“聚类与比较”可复用已完成任务的图；“运行与交付”保存项目方案、导出或载入参数配方。修改参数生成新结果，不覆盖原结果。

样本表支持 CSV/TSV，必填 `id,path`，可选 `sample,kind,modality,condition,batch,counts_layer,prefix,filtered_path,raw_path,clusters_tsv`。相对路径按样本表目录解析。一个捕获一行；同一样本的技术捕获可有相同 sample。内置参考的稳定 ID、物种与发布信息见 [参考清单](resources/references.json)。自定义 TSV 需要 gene_id、compartment（mitochondrial 或 plastid），也支持分组 JSON。

每个工作位的「流程全览」可按已有数据选择起点。「查看本步操作与判断依据」说明输入、操作、判读和交接。文件分区、独立文件管理器和结果可视化均可阅读本地 HTML 报告。FastQC 和 MultiQC 保留报告内的目录和图表交互，「整页阅读」可在新标签展开。拆分式网页的脚本、样式、图片和数据须位于报告所在目录或其子目录；离线预览使用本机资源。

文件预览支持 Markdown 内的项目相对链接、PDF、常见浏览器图像、表格、日志和压缩的测序文本。H5AD/H5 显示对象结构和可识别的矩阵维度，ZIP 显示成员目录，Parquet 显示行数、字段类型及适合预览的数据样例。文本按开头 128 KiB 读取，表格最多显示 100 行，可下载原文件。

### 当前计算环境

FastQC、MultiQC、STARsolo、拟南芥定量索引、DropletUtils 与 SoupX 已在本机实跑。SoupX 使用工作台专属的 WSL 环境，Micromamba 的解析清单位于实验记录本。迁移机器时，先运行 Setup.ps1 还原锁定的 Python 环境；可用项目 Python 执行 resources/prepare_starsolo.py，从已登记的来源下载并校验内置定量资源。迁移 Windows 的 SoupX 计算端时可运行 resources/prepare_soupx_wsl.py，脚本复核已锁定的依赖和实际 R 包版本。其他组装可在“测序与定量”中指定索引，或用未压缩的配套 FASTA、GTF 建立索引。

标准 10x 3′ v3/v3.1 默认使用 16 nt 条码与 12 nt UMI。仅在实验记录证实为 v3 且 R1 截短时选择界面中的 10 nt UMI 选项。

若组件在项目内升级过，较早任务可通过当前环境的 backend/replay_run.py NEW_DIRECTORY --from RESULT_DIRECTORY 使用归档计算代码复现。保留原始输入、对应的软件环境及定量参考。
