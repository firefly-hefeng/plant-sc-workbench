# PSW-004 · 模块接口、文件管理及结果工作区

登记于 2026-11-18，Asia/Shanghai。本次基于 PSW-003 的实现，响应研究者关于模块化、Files / Plots 独立页面和多任务质量控制的修改意见。

**预先登记的问题**  
新任务是否能引用确切的输入、参数、阶段产物与来源？切换两个任务或项目时，图像、目录和运行状态是否属于正确的任务？

| 检验 | 通过条件 |
|---|---|
| 组件接口 | 每种任务及计算块有命名输入和输出；真实矩阵的每个必要输出可定位到文件或对象中的实际字段；旧任务按历史收据读取 |
| 文件与图形 | 独立 URL 支持刷新返回；从目录树打开真实文件；从项目中新建目录；任务切换产生相符的图、来源及下载 |
| 多任务 | 同时提交至少三项任务，记录并发上限、等待状态、排队取消和成功输出；跨项目读取任务时正确校验所有权 |
| 科学等价性 | 使用已暴露的拟南芥 1,200 核矩阵检查 GUI 与 Harness 的共享入口；与前轮相同参数的基准对象比对 |
| 适用范围 | 声明逐模块的适用条件、失败或复核信号、参考文献和实测材料；算法或人群外推单独计证 |

变更仅在本项目内实施。验证时使用测试任务、自建目录或临时注册库，保留现有科研结果。

## 实验材料及方法

2026-11-18，本机 Windows + WSL。使用已公开的拟南芥花分生组织 GSM5320262 的 1,200 核矩阵及配对 FASTQ 的一百万对读段子集、已登记的模拟背景液滴夹具。独立索引构建另用固定随机种子 811 的 64 kb 合成格式夹具，检验索引的可生成性和来源记录。矩阵沿用既有基准运行的默认参数和随机种子 42。外部工具版本、实际层、参考、样本信息及覆盖参数见每次运行的参数文件、收据与模块清单。以上材料在开发期间可见。

| 验证 | 实测结果与原始记录 |
|---|---|
| 输入与输出接口 | 13 个计算模块均有类型化输入输出，12 种可提交任务全部实跑。收据绑定真实文件、对象字段、父任务和有效参数。父任务缺少邻居图时，UMAP 在预检即被拒绝。[主流程](workspace-v2-jobs.json) · [单模块与上游独立任务](workspace-v2-components.json) |
| 各种起点 | 真实矩阵、模拟 raw 液滴与真实 FASTQ 子集分别完成到聚类的路径。另行执行了独立测序质检、定量和 STAR 索引构建。FASTQ 指纹包括选中读段、实际索引文件和白名单。|
| 跨项目多任务 | 同时提交四项作业后观察到两项执行、两项等待；取消其中一项等待任务。包括后续提交在内的六项计算完成。整个观测期的并发峰值为 2。用另一项目读取该任务接口被拒绝。[队列与项目隔离](workspace-v2-jobs.json) |

| 文件与来源完整性 | 14 次验收运行覆盖所有 12 种任务入口。用与计算进程独立的程序逐一复算输入与产物的 SHA-256，按绝对路径去重后 730 个文件，共 2,094,595,848 字节。实际产物集合与每次收据列出的集合一致，收据自身单列。[逐运行文件数](workspace-v2-integrity.json) |

## 数值差异的发现与纠正

第一轮独立拆分时，全流程与分步流程的 HVG、PCA、邻居距离、UMAP、Leiden 及条码一致，但连通权重差了 24 项。将同一张图分别交给 UMAP 和 Leiden 后，定位到 UMAP 对工作用稀疏缓冲区的修改。旧全流程在 UMAP 后导出的图含 24 个显式零值。原非零值中最大为 0.0017449549632146955。此次改为给 UMAP 传递单独的连通矩阵副本，增加了模拟底层函数改写输入的回归测试。

修正后，本轮完整任务 `96372e2a35bc47d9` 与“QC → 特征 → PCA → 图”完全一致，从图任务 `b2716d20bc5d4828` 分别运行 UMAP 和 Leiden，两个分支的图都保留每个输入权重。HVG、PCA、连通权重、UMAP、Leiden、整数计数和条码顺序七项等价检验全部通过。在该材料上，修正前后二维坐标和分区一致。独立运行 Leiden 在缺少 UMAP 时可从分区比较表绘制 ARI 图。[原基准差异](workspace-v2-jobs.json) · [新基准与分支的逐项比对](workspace-v2-components.json)

## 适用范围

并发结果只验证了本机默认 2 槽配置；每作业 CPU 和内存硬配额、跨主机调度与完整规模 FASTQ 的资源消耗未在本轮评估。自动验收确认了计算交接和输出复现。作物间泛化、稀有细胞保留、去污染和双细胞识别的生物学准确率需要独立材料。早期模拟已出现真实加入率 6% 与 SoupX 估计 19.6% 的差异，继续保留估计结果、原始计数层和人工复核入口。[既有材料与适用范围](验收汇总.md) · [工作台使用及方法依据](../docs/模块接口与多任务.md)
