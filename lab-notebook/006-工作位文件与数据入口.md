登记于 2026-11-18，Asia/Shanghai。在本机已完成的五项目验收基础上，调整分析步骤入口及文件呈现方式。独立分区和已有任务保留原地址。

## 材料与方法

2026-11-18 晚间，Windows 本机 8876 服务，使用项目锁定的 Python 环境、Scanpy/igraph 和独立的 Edge 浏览器会话。科研任务全部写入验收项目。质控夹具来自已有的模拟液滴试验，过滤 MEX 有 600 个条码、500 个基因。另从拟南芥 GSM5320262 的既有 1,200 核分析对象导出一个精简 H5AD，保留细胞轴和原始连通权重，移除已有标签、坐标、距离和样本元数据。精简对象的 X 为占位矩阵，仅用于图输入。归档图来自任务 `96372e2a35bc47d9`，固定分辨率 0.5、1.0 和种子 42。

## 观测与核对

| 检验 | 实际观测 |
|---|---|
| 从空项目做 QC | 上传 MEX 三个成员文件，浏览器预览成功，独立 QC 保留 600/600 个条码。随后以文件夹上传再次识别全部三个成员。选择状态跨浏览器会话恢复，交付页和 QC 页可保留不同勾选。此次输入与 UI 试验关闭双细胞估计。 |
| 从空项目做 Leiden | 上传精简 H5AD 后在聚类页提交，无父任务。收据路径和 SHA-256 与上传源一致。两个分辨率和种子复查的 ARI 均为 1.000，样本列为“未登记”。缺少连通权重的文件在登记前被拒。 |
| 五个单模块 | 从 600×500 QC 对象起步，依次以外部文件运行特征和 PCA，再建图。UMAP 与 Leiden 分别读取同一建图产物。五次均成功，逐个复核输入哈希。再用父任务入口运行 Leiden，结果与文件入口逐细胞标签完全一致。 |
| 目录、预览与历史 | 浏览器原位打开真实 QC 图和分区比较表、从输入打开源目录。重新打开五个既有项目，逐一检查活动工作位的结果路径和分区页。旧定量输出复用时，确认捕获 Flower、独立样本 SRR14574910、raw/filtered 配对和重复捕获拦截。历史项目验证拦截了草稿保存请求，直接读取原归档并调用真实配方预检。 |
| 自动回归 | 25 项单元测试全部通过，包含上传中断、重名、缺少 MEX 成员、不成对读段和按模块检查 H5AD 字段。桌面与 390 px 窄屏复核，成功验收的浏览器会话未报告脚本错误。 |

## 偏差与解释范围

首轮数值对照脚本按 `leiden_1` 取列，实际归档键为 `leiden_1_0`。核对命名并修正测试后，从空项目重跑。旧项目的多选交互测试改用稳定的捕获 ID 绑定点击，随后通过。五个历史项目本轮复核原归档与界面，重新计算发生在独立验收项目中。ARI 和标签一致性验证了入口之间的计算复现，细胞类型与分辨率的生物学适切性仍需结合实验设计评估。
