## 发现、修改与保留的边界

1. 常规 v3 使用 12 nt UMI。真实归档数据的 R1 长 26 nt，默认配置按预期拒绝运行。加入明确的短 UMI 选项，保留原始判断和两种布局的回归测试。v2、5′、板式测序等其他化学体系可以导入合格的整数计数矩阵。
2. 中文项目路径导致旧 Windows JVM 加载失败，SciPy 直接写 Matrix Market 文件也遇到原生路径问题。修复为已核对目标的本机路径映射及 Python 二进制文件流，已在原项目路径下重新实跑。
3. Windows R 的部分原生包完成计算后在退出时崩溃。已将 SoupX 切换到独立 WSL 环境；测试要求子进程正常退出且输出可读。emptyDrops 在本机独立 Windows R 4.6.2 上运行。两份 R 会话版本均保留。[DropletUtils 运行环境](../validation/raw-adapters/droplet-versions.txt) · [SoupX 运行环境](../validation/raw-adapters/soup-versions.txt)
4. 中等规模捕获的 Scrublet 计算遇到近邻稀疏数组接口差异。已将其改为 Scanpy 支持的精确近邻方式并验证 6,135 个候选条码均完成评分。大型捕获的双细胞评分成本需另行测量。
5. 本机已完成的 FASTQ 路线使用 STARsolo。Cell Ranger 10 留有 Linux 适配接口，本次未安装验证。内置全基因组定量索引仅覆盖拟南芥 TAIR10。水稻和玉米预装的是相应组装的细胞器基因集，使用 FASTQ 时需要相符索引。
6. 数据集均为已公开、开发期间已接触的材料。组织外推、稀有细胞保留、双细胞灵敏度与特异度、完整 FASTQ 文库性能及研究者实际操作体验仍待独立实验。
